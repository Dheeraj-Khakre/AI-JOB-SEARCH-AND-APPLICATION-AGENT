Act as a Senior Python AI Engineer, AI Agent Architect, Backend Developer, and Full-Stack Developer.

I want you to build a production-ready, end-to-end Personal AI Job Search and Application Agent.

The application should work as my personal AI recruitment assistant. It should automatically discover relevant job opportunities, analyze job descriptions, customize my resume according to each job, assist with job applications, and generate personalized interview preparation questions and answers.

Do not build just a chatbot. Build a complete functional application with real backend APIs, database integration, AI agents, browser automation, frontend, authentication, and deployment configuration.

## 3. MULTI-AGENT ARCHITECTURE

Create independent AI agents with clearly defined responsibilities.

### Agent 1: Job Discovery Agent

Responsibilities:
- Search for Java Backend Developer jobs.
- Search company career pages and supported job platforms.
- Accept manually submitted job URLs.
- Integrate supported job APIs where available.
- Extract company name, job title, location, salary, experience and application URL.
- Filter jobs based on my profile.
- Remove duplicate job listings.
- Store discovered jobs in PostgreSQL.

Add configurable filters:
- Minimum and maximum experience.
- Preferred location.
- Expected salary.
- Employment type.
- Technology stack.
- Remote, hybrid or onsite.

### Agent 2: Job Description Analyzer Agent

When a job is discovered:

1. Fetch and parse the job description.
2. Extract mandatory skills.
3. Extract optional skills.
4. Identify required experience.
5. Identify responsibilities.
6. Identify qualifications.
7. Identify technical interview topics.
8. Identify keywords relevant to ATS.
9. Compare the JD against my candidate profile.
10. Generate a job compatibility score.

Return structured JSON containing:
- Job requirements
- Matching skills
- Missing skills
- Experience compatibility
- ATS keywords
- Suggested preparation topics
- Overall match score

Never present an AI-generated compatibility score as an actual employer ATS score.

### Agent 3: Resume Optimization Agent

This is one of the most important agents.

Inputs:
- My original resume in PDF or DOCX.
- Candidate profile.
- Job description.

Responsibilities:

1. Parse my existing resume.
2. Extract education, employment, experience, projects, technical skills and achievements.
3. Compare resume content with the JD.
4. Identify missing relevant keywords.
5. Improve the professional summary.
6. Reorder relevant technical skills.
7. Rewrite existing experience bullets professionally.
8. Improve project descriptions.
9. Optimize resume structure for ATS parsing.
10. Generate a job-specific resume.

Resume generation requirements:
- Single-column format.
- ATS-friendly headings.
- No unnecessary graphics or icons.
- Standard fonts.
- Relevant technical keywords.
- Quantified achievements only when supported by actual information.
- Preserve factual accuracy.
- Export PDF and DOCX.

Save each tailored resume separately.

For every resume, generate:
- Original resume.
- Tailored resume.
- Changes made.
- Keywords added.
- Missing qualifications.
- Resume-to-JD match score.

Never invent work experience or claim that I used technologies professionally when I have only studied them.

### Agent 4: Job Application Agent

Use Playwright for browser automation.

Responsibilities:

1. Open the job application URL.
2. Navigate the application form.
3. Identify required fields.
4. Fill candidate details using my saved profile.
5. Upload the correct tailored resume.
6. Prepare cover letters when requested.
7. Answer application questions using verified profile information.
8. Validate all fields.
9. Show the completed application for my review.

IMPORTANT HUMAN APPROVAL RULE:

Before clicking the final Submit or Apply button:
- Show the company name.
- Show the job title.
- Show the application URL.
- Show the resume being uploaded.
- Show all application answers.
- Ask me for explicit approval.

Only submit after I approve.

Never bypass CAPTCHA, MFA, access restrictions or website security controls. Respect the terms of service of job platforms. If automation is unsupported, provide a manual application workflow.

Store application confirmation and status after successful submission.
